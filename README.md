# Nailong_Game：奶龙异世界七日冒险
## 项目简介
一款基于原生 HTML + CSS + JavaScript 独立制作的短篇文字互动网页游戏，共11个独立游戏页面，设计4种差异化结局。玩家将陪伴可爱的异次元奶龙度过七天时光，通过探险、烹饪美食、投喂互动、日常对话积攒快乐能量，第七日结束后根据能量数值触发不同分离结局。
游戏内置智能对话系统，接入通义千问大模型还原动画原版奶龙软萌人设，支持实时短句互动；本地存储完整存档系统，昵称、鸡腿数量、快乐能量、日记、探险进度、游戏天数全部永久保存，关闭页面后再次打开无需重复登录。

## 游戏世界观
你意外捡到来自异世界的奶龙，它必须在7天内收集足量快乐能量，才能开启次元大门返回故乡。若七日积攒的能量不足，奶将永远滞留现实陷入沉睡，每一次选择都会轻微影响最终走向。
游戏包含烹饪支线、河岸剧情线索、地图多区域探险、日记记录、投喂系统、AI聊天等完整玩法，节奏轻松治愈，画风柔和童趣。

## 游戏内容与页面结构
本项目合计11个交互页面，包含主页、多个支线场景、结局页面：
1. 主交互大厅主页：包含功能跳转按钮、投喂弹窗等
2. 多阶段烹饪鸡腿剧情页
3. 河岸线索剧情页
4. 多区域探险地图
5. 玩耍互动页面
6. 结局页面

### 四大结局
可能触发四种不同的结局：（为了不剧透玩法，此处不作详细介绍）
1. 遗憾结局
2. 马戏团结局
3. 异地牵挂结局
4. 永久通讯结局

## 项目开发说明
1. 技术栈
纯原生前端三件套 HTML / CSS / JavaScript，仅使用浏览器原生 localStorage / sessionStorage 实现本地存档；
兼容所有主流浏览器（Chrome、Edge、Firefox等），PC端均可正常访问适配。
2. 功能模块设计
- 本地账户系统：支持多昵称独立存档，退出登录清空临时会话
- 动态弹窗系统：投喂、剧情、未解锁提示分层弹窗
- 大模型对话模块：独立封装请求逻辑，角色人设固定适配游戏氛围
- 日历天数自动判定：可以留意一下每日日记噢
- 多分支进度存储：烹饪解锁进度、探险场景解锁状态独立存储
3. 资源说明
仓库内 `images` 文件夹存放游戏全部背景、角色、结局插画，所有图片均为本项目配套素材。
